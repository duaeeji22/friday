ABOUT THE CLASS

화면을 만드는 것을 넘어,
경험을 디자인합니다.

이 수업은 User Interface Design의 기본 원리부터 실제 디지털 화면을 설계하는 과정까지 단계적으로 탐구합니다. 정보의 구조, 시각적 위계, 컴포넌트와 인터랙션을 이해하고 사용자가 자연스럽게 이해하고 사용할 수 있는 인터페이스를 직접 디자인합니다.

WHAT WE LEARN

작게 보고, 깊게 만들기.

01

Interface Thinking

사용자와 정보의 관계를 관찰하고 화면의 구조와 흐름을 설계합니다.

02

UI Visual System

Typography, Color, Grid, Component를 활용해 일관된 UI 시스템을 구축합니다.

03

Prototype

정적인 화면에서 실제로 작동하는 프로토타입까지 아이디어를 구체화합니다.
